# AquaOS

AquaOS is a retail operations and customer relationship platform for local aquarium stores and aquarium service businesses.

## v0.1 focus

- Clean owner analytics dashboard
- Revenue and sales reporting
- Detailed merchandise and livestock inventory
- Inventory insights and reorder workflows
- Customer and aquarium profiles
- Service scheduling and overdue-service alerts
- Vendor management and reporting

## Planned architecture

- Next.js App Router + TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- Zod validation
- Recharts for dashboard visualizations

See `docs/PRD.md` for the product requirements and `docs/ARCHITECTURE.md` for the implementation plan.
